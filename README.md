# Sistema de Gestión de Consolas de Videojuegos

## Descripción
Este sistema ha sido desarrollado como parte de la evaluación práctica de la asignatura Fundamentos de Programación. Su propósito es permitir a una cadena de tiendas de videojuegos administrar eficientemente su catálogo de consolas, gestionando datos descriptivos y comerciales mediante estructuras de diccionarios.

## Funcionalidades 
- Agregar consola: Permite registrar una nueva consola validando que la sigla sea única y cumpla con los formatos requeridos.  
- Buscar consola por sigla: Consulta los datos descriptivos y comerciales de una consola específica mediante su sigla. 
- Eliminar consola: Permite retirar una consola del catálogo, eliminando sus registros de manera sincronizada. 
- Mostrar todas las consolas: Despliega un listado completo con toda la información almacenada en el sistema.

## Cómo ejecutar
1 - Asegúrate de tener instalado Python en tu equipo.

2 - Descarga o clona el repositorio en tu computador.

3 - Abre una terminal en la carpeta donde se encuentra el archivo consolas.py.

4 - Ejecuta el programa utilizando el comando: python consolas.py
